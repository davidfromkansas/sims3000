# Great Pyramid — original directional model

Geometry: `dist/great-pyramid-model.js`. Original square limestone courses on a sand-colored base, with subtle world-facing block variation. Four cached depth-rendered views replace the former static city sprite and serve gallery previews. The original 4×4 gameplay footprint remains unchanged. Course count and game-scale geometry are simplified authored choices.

Reference: [Egypt Ministry of Tourism and Antiquities: The Great Pyramid](https://egymonuments.gov.eg/monuments/the-great-pyramid/), describing Khufu's pyramid and local limestone construction. No source image or original game geometry was copied. PNGs in `renders/` were generated directly from the original geometry. Offline views 0 and 3 were inspected. Browser review remains pending.
