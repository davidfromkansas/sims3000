# Eiffel Tower — original directional model

Geometry: `dist/eiffel-tower-model.js`. Original lattice box girders, four splayed legs, curved arches, three viewing levels, upper cross-bracing and antenna. Four cached depth-rendered views replace the former static city sprite and also serve gallery previews. The original 3×3 gameplay footprint is unchanged. Eight-sided beam approximations, proportions, colors and detail density are authored for this reconstruction.

Reference: [Eiffel Tower official figures](https://www.toureiffel.paris/de/monument/zahlen) and [official architectural history](https://www.academiedesbeauxarts.fr/sites/default/files/inline-files/lettre-de-l-academie-the-tower-eiffel.pdf). No source image or recovered game geometry was copied. PNGs in `renders/` were generated directly from the original geometry. Offline view 0 was inspected before upper bracing was added; corrected views 1 and 2 were inspected afterward. Browser review remains pending.
