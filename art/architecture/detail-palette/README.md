# Visual detail selection review

Five original previews are generated by `detailSwatchSVG` from the same clipped polygons used for anchored wall details. The SVG files preserve the default palette; `swatches-review.png` is a two-times-scale polygon rendering that was visually inspected. They are authored designs, not the complete original detail catalog. Groups (All details, Windows and doors, Trim and ventilation) are authored organization.

In Building Architect, choose Place anchored wall detail. Select each preview, switch the detail set, and place a window or cornice. Change the building accent color and check the updated preview. Sample an existing detail while another set is selected: the sampled selection should become visible. Undo, Apply and reload the city. Changing a design or size during a pending placement must cancel that placement. Selection controls are disabled during sampling and erasure; the sampled design remains visibly selected.

Focused palette and composed editor tests passed. Browser layout/interaction acceptance remains pending.

Reproduce the full color review with `node scripts/render-detail-palette.mjs` followed by `python3 scripts/assemble-detail-palette.py`. The latter checks SVG polygon bounds and renders the exact preview polygons using Pillow. `color-variants-review.png` shows default, terracotta and night palettes; all fifteen previews were inspected. These variants are review inputs, not additional selectable detail designs.
