# Playable feedback checkpoints

The in-game Roadmap now organizes feedback into eight capability checkpoints: founding a town, utilities, finances, civic services, transport/documentation, disaster/prepared challenges, building design, and advanced scenario authoring. Each has three concrete tasks, a focused feedback prompt and a shortcut to the relevant game tools. The header points to eight checkpoints instead of a stale milestone-six label.

Notes for the original six milestones retain their existing local-storage keys. Optional task checkmarks use separate validated keys and are explicitly player-reported, not automated simulation results. The roadmap shows saved task counts and whether notes exist. Download includes the current notes and task selections, including unsaved edits; downloading does not overwrite saved feedback or transmit it. Storage failures leave download available. Opening another checkpoint resets its scroll position and focuses the close control.

All 222 suites passed. The final focus adjustment also passed the targeted feedback test and browser checks. Tests cover the eight definitions, unique step IDs, legacy note preservation, malformed/duplicate step filtering, storage failure, local save, current-draft export, tool dispatch and unchanged earlier notes. Browser QA verified all eight cards, building-design and scenario tool shortcuts, and scroll/focus restoration with no errors. QA did not save test feedback or alter city state.

Feedback checkpoint: open Roadmap, choose a capability, try its three tasks, save notes, and download them when ready to share in this task. These checkpoints organize the current playable scope; they do not claim complete manual parity or represent user acceptance.
