# Emergency response screen

The active disaster warning is followed immediately by response controls and damage counts. Riots prioritize police, locusts prioritize crop dusters, tornado warnings prioritize the siren, and other active disasters emphasize firefighters. Continue and Go to disaster remain directly available.

Reference guidance uses native expandable sections, with the relevant disaster guide open automatically. Random settings remain accessible in their own section. Existing response mechanics and saved state are unchanged.

Browser checks verified visible firefighter controls in the first viewport, actual dispatch selection, and quick siren activation updating shelter state while disabling repeat warnings. Feedback: can you find the right response without searching through instructions for other disasters?
