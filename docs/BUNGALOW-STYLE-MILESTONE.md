# Craftsman bungalow building style

Players can query a residential building and use building replacement to select an original Craftsman bungalow illustration. The replacement applies to the selected style throughout the city, persists in saves and building sets, and can be reverted. Existing cities retain their selected artwork.

The generated transparent PNG adds warm ochre walls, a terracotta roof, a porch and a lawn. Single-tile buildings display the illustration; larger footprints continue using the existing procedural models. This is a visual replacement and changes no population, money, services or growth.

Validation: replacement, persistence, historical vacancy and revert assertions added to the existing replacement suite; full suite validation recorded in the milestone PR. Save schema remains 128 because this is an additive style catalog entry.

Feedback: inspect a detached home, choose Craftsman bungalow, and compare roof visibility and scale at different zoom levels.
