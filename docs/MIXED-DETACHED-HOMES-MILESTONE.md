# Mixed detached-home artwork

City view offers an optional Mixed detached homes setting. Single-tile low-density homes alternate between the existing detached house and the original generated Craftsman bungalow. The selection uses lot coordinates and city seed, so it does not flicker or change as buildings age, become historical or are abandoned.

The default remains off. This browser preference does not change city saves, simulation values or building style identities. Explicit style replacements and custom designs take priority. Larger lots retain their existing procedural artwork. Default view resets the option, and Apply/Cancel use the existing draft controls.

Validation covers both variants, stability, historical/abandoned continuity, override priority, city immutability, preference persistence and the real view-dialog handlers. Browser visual review remains pending while the Mac is locked.
