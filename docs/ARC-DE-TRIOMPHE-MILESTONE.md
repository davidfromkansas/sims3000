# Arc de Triomphe landmark

Players can select the Arc de Triomphe from Landmarks and place it on a clear, level 3 × 3 lot. It is free, has no monthly upkeep and follows the existing one-of-each rule. Demolition and rebuilding operate on the full lot. It participates in landmark scenario goals and alien landmark targeting.

The card uses one original Imagegen illustration with transparent alpha. The city uses original geometric masonry, open central and lateral archways, cornices and simplified relief figures, rendered for all four rotations. The generated illustration was visually inspected before integration; the production model drawing was also rendered offline and inspected in four views. This is stylized artwork rather than a measured architectural replica.

The [official Prima guide, landmark directory p.423](https://www.scribd.com/doc/303581554/SimCity-3000-Unlimited-Prima-Guide) includes the Arc de Triomphe. The 3 × 3 lot is a reconstruction choice. The full original landmark catalog remains unfinished.

Save version 130 recognizes the new type; earlier saves remain supported. The expanded landmark suite checks placement, uniqueness, scenario counts, full-lot demolition/rebuilding, legacy gates, saved simulation continuation and all four bounded model projections.
