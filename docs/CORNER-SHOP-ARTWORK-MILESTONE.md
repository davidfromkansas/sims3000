# Corner shop artwork and mixed shops

Adds an original generated corner bakery with a sage-green upstairs apartment, brick shopfront and burgundy awning. Players can select Corner shop and apartment in building replacement, or enable Mixed neighborhood shops in City view to alternate it with the original single-tile shop illustration.

The mixed view is stable by lot and seed, defaults off, and preserves style identities. It works independently of mixed homes. Explicit replacements and custom models take priority. The illustration represents a commercial building only; the apartment detail does not create residential population. Larger footprints use existing procedural models.

The transparent generated PNG was visually inspected before integration. Validation covers stable shop variation, history/abandonment, independent home settings, replacement save/load and building sets, custom priority, and view controls.
