# Courtyard building lots

Players can now mix courtyard apartments into larger medium-density residential lots using Mixed apartment buildings in City view. Explicit Courtyard apartments replacements also create a distinct larger-lot model. The original procedural brick model has four-story wings, an open court and an entrance, with correct rectangular proportions through all four camera angles. Single-tile lots retain their generated artwork.

Appearance follows the lot root and city seed; custom designs and footprint-specific replacements take priority. This changes no population, demand, services or save schema (134). Larger detached-home/shop variants remain unchanged.

Validation: save continuity, all member identities, abandonment, replacement/custom precedence, bounded drawing at three footprints and four rotations, and the existing actual renderer branch test. Offline renders of the production geometry were visually inspected. Browser acceptance remains pending while the Mac is locked. Publication remains blocked pending explicit Sites source-export authorization.
