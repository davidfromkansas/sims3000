# Separate library and museum maps

Library access and Museum access maps expose their independent adult learning coverage. A neighborhood can be served by one and lack the other. The existing combined adult access map remains available. Civic services provides direct buttons with current citywide percentages; City data, navigation and City view use the shared layer catalog.

Occupied homes use actual road-connected, funded service coverage. Each map labels only its relevant facilities. Gray means no occupied residential demand; inactive facilities use the existing orange markers. No artificial circular service radius is drawn for capacity-based education facilities.

Validation covers different library/museum colors before and after construction, relevant facility markers, disconnected neighborhoods, funding/strike changes, save/load, and actual dialog control handlers.
