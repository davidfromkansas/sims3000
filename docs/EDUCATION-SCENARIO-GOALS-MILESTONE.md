# Create education challenges

Scenario Creator now offers Adult education, School access (ages 0–14), College access (ages 15–24), Library access and Museum access. Each supports a 0–100 target and reads the corresponding live simulation value. These citywide values also appear in event conditions and scenario-program metric selectors.

Players can create challenges requiring complementary services, separate youth teaching stages, or a chosen adult EQ. Existing hold durations, stage ordering, deadlines, script conditions and replay use the same metric registry.

Validation covers allowed ranges, condition evaluation, a custom three-goal challenge won through normal construction, saved continuation and restoration of the starting city. Serialized objects match after load; JSON property order is not part of the save format.

Feedback: create a challenge with library access, museum access and adult education goals, save it, and compare service access with the slower education outcome.
